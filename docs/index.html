Coding Agents Are Zero-Shot Coordinators

Shashank Reddy Chirra1, Ryo Nakahashi2, Shimon Whiteson1, Jakob Foerster1

1 BOLD, University of Oxford 2 Sony Interactive Entertainment

Code

Can independently developed AI agents coordinate with one another and with humans?

We find that coding agents can generate policies as code and iteratively refine them using only self-play feedback, outperforming current zero-shot coordination methods.

What is zero-shot coordination (ZSC)?

Zero-shot coordination (ZSC) requires independently developed agents to cooperate with unseen partners, including humans.

Why is it difficult?

Agents trained in self-play can develop specialised conventions that work with copies of themselves, but fail when paired with an independently trained partner.

Coding Agents for ZSC

We task coding agents with generating policies that coordinate with unseen partners. They write, test, and refine executable policies using only self-play feedback.

Results

We find that coding agents achieve state-of-the-art results on Overcooked V2 and Yokai in inter-seed cross-play (IXP): pairing policies generated in independent runs of the same method. Their policies also coordinate across model families and on novel Overcooked V2 layouts not included in the original benchmark paper.

Hybrid Method

Unlike Overcooked V2 and Yokai, ZSC methods achieve near-optimal SP and IXP in Hanabi. Yet their learned conventions can differ from human conventions, making human–AI coordination challenging (Dizdarević et al., 2025; AH2AC2).

Coding agents can translate human conventions into code policies, but achieve lower SP and IXP, possibly due to weaker long-horizon belief tracking.

We propose a Hybrid method that combines these complementary strengths, using a fixed code policy to guide self-play. This method achieves comparable SP and IXP to the strongest baselines and the highest cross-play scores with AH2AC2 bots, trained on human gameplay, and the Will-Hanabi bot, which follows human conventions.

Conclusion

Our results show that advances in general model capability address longstanding challenges in zero-shot coordination. Coding agents can independently generate compatible policies, follow human conventions specified in natural language, and guide deep RL policies towards those conventions.
